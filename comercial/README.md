# Área Comercial — Copiloto Comercial

Esta carpeta concentra toda la información, decisiones y documentación relacionada con la estrategia comercial del proyecto.

## Objetivo

Mantener en un único lugar el conocimiento comercial del producto para evitar perder decisiones, repetir análisis o contradecir definiciones anteriores.

## Estructura prevista

- `decisiones/` — decisiones comerciales tomadas, con fecha, contexto y fundamento.
- `precios/` — hipótesis, referencias de mercado, costos, precios objetivo y modelos de cobro.
- `modelo-comercial/` — propuesta de valor, segmentos, oferta, estructura comercial y modelo de negocio.
- `go-to-market/` — canales, prospección, adquisición, ventas y lanzamiento.
- `competencia/` — competidores, productos similares y referencias de mercado.
- `experimentos/` — pruebas comerciales, resultados y aprendizajes.
- `metricas/` — métricas comerciales relevantes y objetivos.

## Regla de trabajo

Una decisión pasa a ser parte de la documentación oficial cuando se toma explícitamente. Las ideas o hipótesis deben quedar diferenciadas de las decisiones definitivas.

Cada decisión importante debería registrar:

1. Fecha.
2. Decisión.
3. Motivo.
4. Alternativas consideradas.
5. Impacto esperado.
6. Estado: propuesta, validada, vigente o descartada.
